## 🔴 SOBRE O PROJETO

A paixão pelo automobilismo ganha vida no **Pit Wall**, uma página web inspirada no universo da Fórmula 1 e no Grande Prêmio de São Paulo, realizado no icônico Autódromo de Interlagos.

Desenvolvido com **HTML5 e CSS3**, o projeto apresenta uma interface moderna e dinâmica, reunindo informações sobre pilotos, equipes, classificação e ingressos em uma experiência visual inspirada no mundo das corridas.

Mais do que uma página, o Pit Wall representa a aplicação prática dos conhecimentos de desenvolvimento web, explorando design, organização e responsividade.

---

## 🏁 CONHEÇA AS SEÇÕES

| Seção | Descrição |
|:--|:--|
| 🏎️ **Página inicial** | Banner principal com destaque para o GP de São Paulo. |
| 🏁 **Pilotos** | Cartões personalizados com pilotos, números e equipes. |
| 📊 **Classificação** | Tabela com posições, equipes e pontuações. |
| 🔎 **Filtros** | Campos para pesquisa e seleção de equipes. |
| 🎟️ **Ingressos** | Informações e formulário para preenchimento. |

## 🎨 IDENTIDADE VISUAL

O design foi inspirado na identidade visual do automobilismo, utilizando cores fortes e contrastantes para transmitir a atmosfera das pistas.

| Cor | Aplicação |
|:--|:--|
| ⚫ Preto | Fundo principal e elementos de destaque. |
| 🔴 Vermelho | Botões, detalhes e elementos gráficos. |
| ⚪ Branco | Textos e contrastes. |
| 🩶 Cinza | Informações secundárias e bordas. |

A combinação de elementos diagonais, cartões personalizados e efeitos de interação reforça a identidade esportiva do projeto.

---

## 📱 DESIGN RESPONSIVO

O Pit Wall conta com adaptações para diferentes tamanhos de tela, proporcionando uma experiência visual organizada em computadores, tablets e celulares.

Foram utilizadas **Media Queries** para ajustar o layout conforme a resolução do dispositivo.
